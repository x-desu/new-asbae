# ASBAE Tech

Professional corporate platform for ASBAE, delivering technical excellence and strategic resource mobilization. This project is a high-performance, animation-rich website built with modern web technologies.

## 🚀 Key Features

- **Interactive UI/UX**: Immersive user experience powered by GSAP animations and smooth view transitions.
- **Performance Optimized**: Leverages Next.js 15 features, including dynamic imports and optimized image handling.
- **AI-Powered Assistance**: Integrated chat widget for real-time user inquiries and support.
- **Service Portfolios**: Detailed sections for services overview, industry-specific solutions, and organizational capability.
- **Responsive Design**: Fully responsive layout using Tailwind CSS, ensuring a seamless experience across all devices.
- **SEO Ready**: Configured with dynamic sitemaps, robots.txt, and metadata optimization.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [GSAP](https://greensock.com/gsap/) (GreenSock Animation Platform)
- **Components**: [Radix UI](https://www.radix-ui.com/)
- **AI Integration**: AI SDK / Vercel AI
- **Deployment**: [Vercel](https://vercel.com)

## 📦 Getting Started

### Prerequisites

- Node.js 18+ 
- npm / pnpm / yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🏗️ Project Structure

- `app/`: Next.js App Router pages and API routes.
- `components/`: Reusable UI components and section-specific modules.
- `lib/`: Utility functions, animation logic, and shared configurations.
- `public/`: Static assets, images, and PDF documents.
- `scripts/`: Maintenance and generation scripts (OG images, favicons).
- `styles/`: Global CSS and Tailwind configurations.

## 🚀 Deployment

The project is optimized for deployment on the Vercel platform.

```bash
npm run build
```
